    Add the Chrome extension

    It warns you inline on ChatGPT, Gemini, Claude, Copilot, Perplexity and more — before you hit send. Runs entirely on your device.

    1. Download the extension. Get the latest release zip → then unzip it. You'll get an extension/ folder.
    2. Open chrome://extensions in Chrome, Edge or Brave.
    3. Turn on Developer mode (toggle, top-right).
    4. Click Load unpacked and select the unzipped extension/ folder.
    5. Open any AI chat site and start typing — the 🛡️ shield appears above the box.

    If you have the repo cloned, build the engine bundle and load the folder directly:

    git clone https://github.com/rohitdvv/shadow-ai-privacy-auditor
cd shadow-ai-privacy-auditor
npm run build:extension
    1. Open chrome://extensions → enable Developer mode.
    2. Load unpacked → choose the extension/ folder.
    Requests only the storage permission and zero host permissions. Its manifest sets connect-src 'none', so it is technically incapable of sending your text anywhere.
